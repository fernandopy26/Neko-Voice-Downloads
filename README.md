# Neko Voice

Laboratório de voz da Neko Studio para criar narrações e trabalhar com a voz em vídeos. Geração local por CPU, interface em português e arquivos no seu computador.

[Baixar a edição de teste para Windows](https://github.com/fernandopy26/Neko-Voice-Downloads/releases/latest)

- Windows 10/11 de 64 bits, processadores Intel ou AMD.
- Extraia toda a pasta do ZIP e abra **NekoVoice.exe**. Mantenha as pastas que acompanham o programa.
- Não precisa instalar Python, Node.js, CUDA ou FFmpeg. Internet é necessária nos primeiros downloads de modelos e vozes.
- Avaliação de **48 horas corridas a partir da primeira abertura**, com vencimento visível. A edição completa é entregue pela Neko Studio após pagamento.
- Projetos e gravações ficam salvos. O fim do teste permite guardar backups; não apaga seus dados.
- Clonar sua voz exige acesso ao Pocket TTS na sua própria conta Hugging Face. Use uma voz própria ou uma amostra autorizada.
- A edição de teste mantém o motor e a qualidade da edição completa. O tempo de geração depende do computador e do roteiro.

Este repositório contém somente a página de downloads e as Releases do teste compilado. O código de desenvolvimento e a edição completa têm distribuição privada. O executável ainda não possui assinatura digital; o SHA-256 acompanha cada ZIP para conferir o download.
